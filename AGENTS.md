# twin-cli

- twin-cli is an agent-agnostic clone-and-run safety tool for coding agents plus a scenario suite.
- Use TypeScript strict mode everywhere, no deprecated APIs, and no `any`.
- core has zero dependency on cli or scenarios.
- Always check SPEC.md and ARCHITECTURE.md before implementing.
- Commit messages explain WHY, not just what.
- Before each meaningful project checkpoint commit, add one concise entry to
  `docs/decisions.md` explaining the main concept learned in your own words, not
  a file-by-file changelog. Use `pending commit` before committing; if the hash
  cannot be known beforehand, replace it with the actual short hash and subject
  immediately after the commit in the next documentation update. Preserve earlier
  entries rather than rewriting history.
